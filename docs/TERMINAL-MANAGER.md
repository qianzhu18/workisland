# 多终端管理

在顶部工具栏打开「终端」，首页会列出本次运行中由 WorkIsland 创建的终端，并显示名称、启动目录和运行状态。点击一行进入，使用「新建终端」创建独立会话；进入后也可以用上方选择器切换，或返回终端列表。

- 每个终端有独立 Shell、输入和输出。返回首页、切换工具或收起灵动岛时，任务继续运行；再次进入会保留输入、历史滚动位置和 TUI 画面。
- 列表右侧可重命名或关闭指定终端。关闭运行中的终端需要确认，会结束该终端及其子任务；其他终端继续运行。自然退出的终端保留退出码和输出，可以重新启动。
- 下方保留设置中保存的快捷命令。每次点击都会新建具名终端执行，避免影响已有任务。
- 最多保留 24 个终端条目，包含已退出条目。达到上限时先关闭不需要的条目。
- 设置中关闭终端功能或退出 WorkIsland 会停止所有内置终端。会话不会跨应用重启恢复；脱离 Shell 自行守护的进程不属于终端生命周期管理范围。

## 已在系统中打开的终端

macOS 首页提供「查找外部终端」。它只在你主动点击时读取已经运行的 Terminal 和 iTerm2 的会话名称、设备标识和忙碌状态，不读取终端文本或命令历史，也不会自动打开终端应用。首次使用可能由 macOS 请求自动化权限；可以在「系统设置 → 隐私与安全性 → 自动化 → WorkIsland」管理授权。

外部会话通过「回到原窗口」操作进入原应用，不会嵌入 WorkIsland 的终端画面。Terminal 没有可靠的按标签页关闭接口，所以只提供跳转，在原应用里关闭；iTerm2 支持按明确会话关闭，若原应用仍在等待关闭确认，WorkIsland 会提示等待确认。列表不会后台轮询，外部窗口有变化时点击刷新。

拒绝权限、宿主无响应或目标已消失时会显示原因，内置终端仍可使用。外部发现目前限 macOS；iTerm2 的真实设备关闭行为需在已安装 iTerm2 的设备验证。

## 开发验证

`npm run check` 覆盖按 ID 路由、关闭隔离、迟到事件、重启代次、快照与实时输出去重、资源上限和权限错误。`scripts/smoke-multi-terminal.mjs` 针对隔离预览执行真实 PTY 与 xterm 交互，支持 `FLUX_DEBUG_PORT` 指定调试端口。脚本会拒绝安装在 `/Applications/` 的应用与含已有终端的预览，只清理本次创建的会话，并恢复隔离设置。
