# WorkIsland internationalization

WorkIsland supports Simplified Chinese (`zh-CN`) and English (`en`). New and upgraded installations default to `system`, which resolves the first supported language from Electron's `app.getPreferredSystemLanguages()`. Chinese, `zh-CN`, and `zh-Hans` resolve to Simplified Chinese; English variants resolve to English; all unsupported language lists fall back to English.

Users can override this in **Settings → General → Language & Region** with **Follow System**, **简体中文**, or **English**. A change is broadcast to every WorkIsland window and rerenders the existing React roots in place. No restart is required, and component-owned state such as the full terminal session is preserved. Native tray labels are rebuilt when the locale changes.

## Adding or changing user-facing copy

1. Add the same semantic key to `src/locales/zh-CN.json` and `src/locales/en.json`.
2. Keep placeholders identical in both catalogs, for example `{name}`.
3. Renderer code must call `t("feature.area.label")`; main-process UI and native dialogs must call `i18n.t("feature.area.label")`.
4. Do not place Chinese presentation strings directly in renderer source. Product names, protocol identifiers, file extensions, and user-provided text stay unchanged.
5. Run `npm run check`. The i18n gate checks catalog parity, placeholder parity, referenced keys, and hardcoded CJK presentation strings across renderer sources and native UI services.

English is the runtime fallback catalog and the macOS bundle development region. The packaged app declares `en` and `zh-Hans` localizations, while WorkIsland's internal locale identifier remains `zh-CN`.

## Verification

For a release candidate, verify both system-language launches and both manual overrides:

- launch with macOS set to English and confirm onboarding, Island, Settings, dialogs, and update notifications are English;
- launch with macOS set to Simplified Chinese and confirm the same surfaces are Chinese;
- switch languages while a full terminal is active and confirm the UI changes without restarting or replacing the terminal session;
- restart once after each manual override and confirm the preference persists.
