# 统一额度与用量入口

用户要求：暂停发布；将 Codex 额度与 API 用量合为顶部一个可排序、可收进更多菜单的插件按钮；默认显示 Codex 剩余额度，悬停或点击展开详情，完成后构建到本机。

已定位：旧 Codex 额度属于固定 leading 区域，只有有效数据才渲染。当前隔离开发实例 getQuotaMap 返回空对象，showUsageQuota 和 codexSubscription 均开启，因此不是被系统状态图标挤掉，而是隔离目录缺少账号数据后隐藏。缺数据不应让统一入口消失。

采用既有 usage 模块 ID、ToolbarTools 自定义 render、PerformancePopover 的 portal 与浮层定位、getUsageSummary 和 getQuotaMap。不新增依赖或余额服务。默认槽位 32px，以 Codex 图标和剩余百分比呈现；无数据为破折号，详情解释不可用。移除固定区域 Codex 格子，其他 Agent 与更新入口保留。现有 usage 排序/收纳偏好继续有效，按 Codex 显示开关隐藏数值而不是隐藏 API 功能。

悬停延迟 240ms 打开，跨入详情不闪退；点击固定，第二次点击/外部点击/Escape/失焦/拖拽关闭。详情置于刘海下方且限制在面板可见区域，提供 Codex 两个窗口、近七天本地 Token/估算成本、打开完整看板按钮。没有真实服务商余额接口，必须明确本地统计不等于账户余额。

验证：额度模型异常/缺失/双窗口/未知定价；实际 Electron 交互覆盖空数据、悬停、点击固定、Escape/外部关闭、拖拽与更多收纳、可视边界；完整检查；本机独立预览启动，保留安装与用户数据。发布不继续，版本号维持 1.5.1。

升级补充：旧 Codex 开启时将入口一次性迁移为可见，保留之后的收纳选择。用量看板关闭但订阅额度仍开启时，统一入口仍可使用。
