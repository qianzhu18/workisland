# 清理会话快捷栏设计（Issue #139）

## 目标

消除会话列表顶部“清理会话”按钮独占一行造成的空间浪费，同时保留批量清理入口，并让用户能够像其他快捷工具一样调整它的位置。

## 交互设计

- 将“清理会话”作为 `clear-sessions` 工具加入现有顶部快捷栏，默认参与快捷栏布局。
- 工具使用垃圾桶线性图标；图标按钮通过 `title` 和 `aria-label` 提供当前语言下的完整名称。
- 工具始终存在，因此用户可以在没有会话时完成排序；没有可见会话时使用 `aria-disabled` 并短路点击，既表达不可执行状态，也不阻断拖拽。
- 有可见会话时，单击一次调用现有 `deleteSessions`，清理当前列表中的全部可见会话；本次不新增确认弹窗，不改变清理范围。
- 工具沿用快捷栏现有的拖拽、左右槽位、溢出菜单、固定与收纳、顺序和槽位持久化能力。
- 删除会话列表内部原有的整行按钮及其专用样式。

## 数据与持久化

`clear-sessions` 进入工具栏可持久化 ID 白名单，并纳入 `toolboxModuleOrder`、`toolbarHiddenModules`、`toolbarModuleSides` 和 `toolbarModuleSlots` 的现有设置合并逻辑。它是操作工具而非内容模块，点击不会改变当前活动页面。

## 国际化与可访问性

复用 `session.clear` 的中英文文案。垃圾桶图标使用 `currentColor`，确保快捷栏、溢出菜单和禁用状态都由现有视觉系统控制。禁用状态使用 `aria-disabled`，保留排序手势。

## 验收

- 会话列表不再渲染 `session-list-actions` 独占行。
- 快捷栏定义中包含 `clear-sessions`，点击会传递全部可见会话 ID。
- `clear-sessions` 的顺序、收纳、左右侧和精确槽位偏好可通过设置合并并在重启后保留。
- 无可见会话时清理按钮禁用；中英文标签均来自 `session.clear`。
- 相关单元测试、源码契约测试和完整 `npm run check` 通过。
