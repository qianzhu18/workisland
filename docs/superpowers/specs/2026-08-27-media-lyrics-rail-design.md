# WorkIsland 媒体歌词栏设计

## 目标

优化多 Agent 场景下左侧媒体区域的纵向空间：媒体控制始终固定在顶部；当灵动岛因右侧会话增多而变高时，下方空间展示与播放进度同步的歌词。歌词不可用时不影响媒体控制和 Agent 监控。

## 已验证事实

- WorkIsland 当前的 MediaRemote 数据包含歌曲标题、歌手、专辑、时长、播放进度、封面和控制能力，但不包含歌词。
- Apple Music 的公开 MusicKit 只公开 `hasLyrics`，没有公开歌词正文接口；Music.app 自动化字典虽有普通歌词属性，但需要应用自动化权限，不能保证流媒体歌曲可读，也没有逐行时间戳。
- 网易云音乐没有面向第三方桌面应用的公开歌词接口，不使用其非官方逆向接口。
- LRCLIB 的公开 API 可通过标题、歌手、专辑和时长返回普通歌词与同步歌词，不需要 API Key，但要求客户端标识、节制请求并遵守限流。
- 2026-08-27 的可行性探测中，《七里香》《海阔天空》和《The Chain》均命中普通歌词与同步歌词，单次响应约 0.83–1.42 秒。该结果只证明链路可用，不代表曲库完整。

参考：

- Apple MusicKit `Song.hasLyrics`: https://developer.apple.com/documentation/musickit/song/haslyrics
- LRCLIB API: https://alice.lrclib.net/docs
- MediaRemote Adapter: https://github.com/ungive/mediaremote-adapter

## 产品原则

1. **不生成歌词**：只展示歌词服务返回的歌词，不使用 AI 编写或补全歌词。
2. **宁缺毋错**：匹配置信度不足时显示“暂未匹配到歌词”，不展示可能属于其他版本的歌词。
3. **媒体控制优先**：歌词加载、解析或网络失败都不能阻塞媒体状态和控制按钮。
4. **Agent 提醒优先**：审批、提问、错误和完成通知继续拥有现有优先级，歌词不改变 Agent 状态模型。
5. **本地优先且透明联网**：歌词查询会发送歌曲标题、歌手、专辑和时长；设置页必须说明来源与发送字段，并允许关闭。

## 交互与布局

### 媒体栏

现有左栏宽度保持 300px，不随右侧 Agent 数量横向移动或重新居中。

左栏改为上下两段：

1. 顶部是现有封面、歌曲信息、进度和上一首/播放/下一首控制，保持固定高度并顶部对齐。
2. 下方是歌词区域，占用右侧会话列表撑高后产生的剩余空间。

当可用高度不足时，仅显示媒体控制，不强塞歌词。歌词区域出现和消失使用轻微透明度过渡，不改变左栏宽度，不推动右侧 Agent 内容。

### 同步歌词

- 根据 MediaCard 已投影的实时播放位置选择当前歌词行。
- 当前行使用较高亮度和字号；前后各显示若干行作为上下文。
- 当前行变化时平滑滚动到视觉中心，但用户手动滚动后短暂停止自动跟随，数秒后恢复。
- 拖动媒体进度、切歌或恢复播放后立即重新定位当前行。

### 降级状态

- 只有普通歌词：展示可滚动全文，不做伪同步。
- 纯音乐：显示“纯音乐”。
- 未命中：显示“暂未匹配到歌词”。
- 正在加载：显示低干扰的“正在匹配歌词…”。
- 离线、超时、限流或服务异常：显示“歌词暂不可用”，媒体控制继续工作。

## 数据架构

### LyricsService

新增独立主进程服务，不把联网和匹配逻辑放入渲染器。

输入为规范化媒体快照，输出为：

```text
idle | loading | synced | plain | instrumental | not-found | unavailable
```

歌词行数据只包含时间戳和文本；错误对象不向渲染器暴露网络或文件系统细节。

### 查询与匹配

歌曲签名由以下字段构成：

- 规范化标题；
- 规范化歌手；
- 规范化专辑；
- 四舍五入的歌曲时长。

首选 LRCLIB `/api/get` 精确查询。标题、歌手或有效时长缺失时不查询。精确查询未命中后调用一次 `/api/search`，但只有在标题和歌手一致、时长误差不超过 3 秒，并且没有更高冲突候选时才采用结果。

切歌时取消旧请求；同一签名只允许一个在途请求。请求串行发送，并使用符合 LRCLIB 要求的 WorkIsland `User-Agent`。遇到 `429` 时遵守 `Retry-After`，不立即重试。

### 缓存

- 使用主进程内存缓存加本机磁盘缓存。
- 正向结果最多保存 30 天；未命中结果保存 24 小时；服务异常不做长期负缓存。
- 最多保留 500 首，按最近使用淘汰。
- 缓存不随应用日志、遥测或诊断包上传。
- 切换到已缓存歌曲时立即展示，不发起重复请求。

### 安全和边界

- 限制歌词响应体大小、行数、单行长度与总字符数。
- 只接受 HTTPS JSON 响应；不渲染 HTML，不执行歌词内容。
- 歌词正文、歌曲标题、歌手、专辑和收听历史不进入遥测。
- 不接入网易云、Apple Music 或其他媒体应用的非公开歌词接口。

## 设置

在“通用 → 工作台 → 媒体播放”的详细设置中增加“在线歌词”。

- 默认关闭，避免在未告知的情况下把收听元数据发送给第三方。
- 开启时明确说明：为了匹配歌词，会把歌曲名称、歌手、专辑和时长发送给 LRCLIB；歌词结果缓存在本机。
- 关闭后立即停止新查询并清除歌词界面；提供独立的“清除歌词缓存”操作。
- 本机验收时可以由测试者主动开启，不修改正式默认值。

## 组件边界

- `MediaService`：继续只负责系统正在播放信息和媒体控制。
- `LyricsService`：负责查询、置信匹配、解析、缓存和限流。
- `media-state`：继续规范化播放状态，不混入歌词生命周期。
- `lyrics-state`：定义歌词状态、LRC 解析和当前行选择等纯函数。
- `MediaCard`：顶部媒体控制和下方歌词展示的组合容器。
- `LyricsPanel`：只负责歌词状态和逐行渲染，不直接联网。

## 测试与验收

### 自动化测试

- LRC 时间戳解析、空行和异常输入。
- 精确匹配、保守搜索回退、错误版本拒绝。
- 切歌取消旧请求，旧响应不得覆盖新歌。
- 正向缓存、负缓存、过期和 500 首淘汰。
- 超时、404、429、无网络、超大响应和非法 JSON 降级。
- 当前歌词行随播放、暂停、拖动进度和切歌正确更新。
- 关闭在线歌词后不产生网络请求。
- 歌词失败时媒体控制和 Agent 面板保持可用。

### 本机验收

- Apple Music、网易云音乐各验证至少一首有同步歌词歌曲。
- 验证中文、英文、纯音乐、无歌词和同名不同版本。
- 单 Agent 矮面板只显示媒体控制；多个 Agent 撑高后歌词自然填充下方。
- 切歌后旧歌词立即退出，缓存命中歌曲即时出现。
- 人工断网后媒体控制仍然正常。

## 非目标

- 不保证所有歌曲均有歌词。
- 不提供歌词编辑、上传、翻译、罗马音或逐字卡拉 OK。
- 不抓取 Apple Music、网易云或网页中的歌词页面。
- 不在本阶段更换现有 MediaRemote Adapter。
