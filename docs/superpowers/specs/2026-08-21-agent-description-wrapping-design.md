# Agent 说明文字完整展示设计

## 问题

设置页的 `.agent-detail` 被统一设置为单行、省略号截断。TraeCode 的连接提示较长，因此用户无法读完必须启用 Hooks 和本地自动运行的说明；未来新增的较长说明也会遇到同样问题。

## 设计

- 所有 Agent 卡片的说明文字允许自然换行，不再使用单行省略号。
- 保留卡片现有三列布局，连接或移除按钮继续位于右侧。
- 卡片高度随文字内容自然增长，图标和按钮保持垂直居中。
- 不修改说明内容、字号、卡片宽度或连接逻辑。

## 验收

- TraeCode 的完整连接提示可见。
- 通用 `.agent-detail` 样式不再包含 `white-space: nowrap`、`overflow: hidden` 或 `text-overflow: ellipsis`。
- 现有设置页和完整项目检查通过。
