# 顶部工具栏改进（Issue #69）

用户已确认：智能体主页固定在工具区左端，设置固定在右端；移除顶部静音按钮，声音仍在设置中控制。清理会话移入会话列表。

实体刘海宽度加 16px 安全间距作为中间不可用区域。左右各使用剩余宽度的一半，右侧采用 32px 槽位。按容量显示用户排序的扩展，其余收进“更多”；保留主页、设置和更多入口。更多菜单位于顶部行下方，按面板高度限高滚动；隐藏扩展提供“置顶”操作。性能监视器和桌宠保留原操作，空间不足时也进入更多。

排序使用 Pointer Events：6px 位移阈值、指针捕获、图标跟随、空槽和相邻按钮 150ms 让位。跨过槽位中点预览插入；释放才保存，Esc、失焦、指针取消、工具栏外释放均取消。使用用户当前排列作为基准，禁用模块保留其位置。拖动后不得产生功能点击；低动态效果模式关闭让位动画。

窗口关闭计时器触发前检查拖动和菜单状态，新展开操作清除旧离开计时器。拖动期间使用现有本地交互锁，结束时释放。

独立实现，无 Atoll 源码或资产复制。开发分支交付本地可安装预览；正式合并与发布另行进行。

验收覆盖：全扩展、窄容量、主页设置固定、真实点击、连续排序、Esc/外部取消、更多菜单与隐藏扩展置顶，以及包内源码一致性。
