# 内置终端的提醒避让

用户已选择：查看终端时统一不切页，保留待处理提醒。范围包含终端列表和完整终端；收起灵动岛或切到其他工具后，自动提醒维持原有设置。

## 行为

- 自动 Agent submission / completion / approval / question / error 到达时，若当前提交的界面是展开的终端页，保持 surface、页面、焦点和终端实例，不新建自动收起倒计时，也不在退出终端后补弹积压提醒。
- 已经存在的通知倒计时，不能在用户进入终端页后关闭它。检查应发生在接收提醒和计时器触发时，避免只保护正在打字的 textarea 而漏掉列表、选择器与阅读状态。
- Agent 会话更新照常处理。终端页提供一个可展开的待处理入口，显示仍在等待审批、等待回答或未撤销的异常会话，用户点击具体项目后才显示对应 Agent 页面。状态解决、会话移除后入口自动更新，不维护第二份过期待处理队列。
- 保留现有声音设置；此次只改变页面自动展示，不改声音策略。普通提交/完成无新增角标。手动打开与其他功能通知不受本规则影响。

## 复用与实现边界

复用现有 session 更新、session-model 可见性、surface 路由和 TerminalPanel；增加一个小型纯策略模块，接收已提交 DOM 中的终端可见标记，覆盖主进程 IPC 到达和倒计时检查。无需新依赖、IPC 或进程探测，也无需按目录猜测 Agent 属于哪一个终端。用户选择的统一避让规则不依赖可靠的 Agent → PTY 身份映射。

此轮不实现终端拖拽分离或接管外部 PTY，它们是后续独立能力。

## 验收

先写策略回归，检查自动与手动、终端可见与收起、待处理去重/排序/解决与异常过滤。再用独立数据目录的真实 Electron / xterm / PTY，通过主进程 IPC 注入 Agent 会话与自动 surface：输入半行命令后依次提交、完成、审批、提问与异常，观察焦点、DOM 身份、当前 ID 和完整画面不变；停留超过旧自动收起时间仍展开；点击待处理项才进入正确 Agent 页；返回终端输入继续；切到其他工具或收起后提醒照常。
