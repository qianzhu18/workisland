# 文件架原生分享、选择与复制设计

## 目标

文件架采用“左侧系统分享区、右侧可选择文件区”：文件展示真实 Finder 图标或 Quick Look 缩略图；用户可调用 macOS 原生分享面板，也可选择、复制或一次拖出多个文件。

## 交互

- 左侧固定为紧凑的“系统分享”卡，使用 macOS 原生分享符号，不再手绘或仿制 AirDrop 图标。
- 点击分享卡，或把文件拖入分享卡，打开 macOS 原生分享面板。AirDrop、微信、备忘录、邮件等项目由本机安装的系统分享扩展决定；用户在 macOS 中启停和调整分享扩展，WorkIsland 不维护容易失效的应用白名单。
- AirDrop 保留为默认快捷操作，并从系统 `NSSharingService` 读取原生名称和图像；系统服务不可用时不展示虚假入口。
- 右侧横向排列文件卡。图片、PDF、视频优先显示缩略图，文件夹及无法生成缩略图的文件使用系统图标。
- 文件名最多两行，中间截断；双击打开。
- 单击选择一个项目；按住 `Command` 点击切换多选；按住 `Shift` 点击连续选择；`Command+A` 选择全部。
- 有选择项时，文件区顶部显示选择数量以及“复制、分享、移除引用”批量操作。
- `Command+C` 或“复制”把选中的本地文件 URL 写入系统剪贴板，使 Finder、微信和其他原生应用可直接粘贴；文本或网址项目按对应内容复制。
- 从已选中的任意文件卡向外拖动时，一次拖出所有已选中的可用本地文件；从未选中的卡片开始拖动时只拖当前文件。
- 卡片悬停显示预览、Finder 定位、系统分享三个图标按钮及右上角移除按钮；所有按钮提供中文 tooltip 和无障碍标签。
- 外部 Finder 文件拖到右侧时加入文件架；拖到左侧时直接打开原生分享面板，不重复加入。
- 原文件和文件架引用在分享、复制或拖出后均不删除。

## 安全与失败处理

- Renderer 只能按文件架 item id 数组请求缩略图、复制、拖出和分享，不能传任意磁盘路径。
- 缩略图由主进程的 macOS Quick Look 能力生成，失败后回退系统文件图标。
- 原生层在执行复制、分享和拖拽前重新解析 item id，并过滤已不存在的文件。
- 原生分享面板或 AirDrop 不可用时显示明确反馈，不静默失败。

## 验收

- 文件夹不再是绿色方块，常见文件能显示系统图标或内容缩略图。
- 分享区使用原生图标，并能弹出包含本机可用目标的 macOS 分享面板。
- AirDrop 快捷入口使用系统提供的名称和图像。
- 单选、Command 多选、Shift 连选和 Command+A 均正确。
- 复制一个或多个文件后，可在 Finder 中粘贴；拖动任意已选中文件可一次拖出全部选择项。
- 操作图标无需阅读按钮文字也能辨认，悬停可看到中文说明。
- Finder 拖入、粘贴、打开、预览、定位、移除引用继续可用。
