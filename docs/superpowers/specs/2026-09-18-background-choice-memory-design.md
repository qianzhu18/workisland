# 背景选择精简与图片记忆设计

## 目标

背景设置只提供用户能明确理解的“纯色”和“自定义图片”。用户选择过图片后，切到纯色再切回图片，应立即恢复上一次裁剪后的图片和遮罩强度，不要求重新上传。

## 状态设计

- `islandAppearance` 继续表示当前生效背景。
- 新增 `lastIslandImageAppearance`，只保存经过校验的 `{ kind: "image", imageRef, imageDim }`。
- 每次成功应用图片时，主进程自动同步更新 `lastIslandImageAppearance`。
- 切换到纯色或恢复默认只修改 `islandAppearance`，不清空图片记忆。
- 旧设置中当前背景本身是图片时，启动合并设置时自动将其迁移为图片记忆。

## 交互

- 设置页移除“磨砂”入口，只显示“纯色”和“自定义图片”。
- 点击“自定义图片”时，优先恢复 `lastIslandImageAppearance`；没有记忆时才打开图片选择器。
- 如果记忆引用的文件已损坏或被外部删除，预览读取失败后显示空态，用户可重新选择图片。
- 旧版 `glass` 背景仍能读取，但设置页将它归入纯色；用户修改颜色或透明度后写回标准 `solid`。

## 验证

- 模型测试覆盖：`glass` 映射到纯色、图片记忆优先恢复、无记忆时返回空值。
- 设置合并测试覆盖：当前图片迁移为图片记忆、切换到纯色后记忆仍保留。
- 设置 UI 静态契约覆盖：只呈现两个材质入口，图片点击使用记忆，缺少记忆才选择图片。
