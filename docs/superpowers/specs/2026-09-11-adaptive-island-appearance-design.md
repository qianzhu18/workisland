# WorkIsland 自适应 Island 外观设计

日期：2026-09-11  
关联：GitHub Issue #148

## 目标

让用户可以自由选择 Island 背景颜色，并把背景不透明度从 100% 调至 0%，同时保持文字、图标和系统性能入口清晰。透明度只作用于背景，内容本身始终保留。

本次只处理三个已确认问题：换色后透明度滑块仍不可用、浅色或透明背景下的前景可读性、系统性能圆环中心的硬编码黑色。

## 已确认根因

设置页按当前 `islandAppearance.kind` 创建透明度控件。默认背景会生成一个 `disabled` 的滑块；用户换色时 `save()` 只更新状态并等待设置事件，没有重绘当前外观页，因此旧滑块继续保持禁用。关闭后重新打开设置会重新渲染，滑块才根据新的 `solid` 状态启用。

Island 的背景目前只写入 `--island-bg`。其余前景样式仍大量使用固定白色或灰色，性能圆环中心也固定为 `#0b0c0f`。现有亮度保护只会压暗用户选择的颜色；当背景透明后，最终视觉还包含未知桌面壁纸，所以不能只依赖所选颜色推导可读性。

## 方案：Adaptive Glass

### 1. 颜色与透明度交互

- 自定义颜色或背景预设保存成功后，立即重绘外观区域，使透明度滑块在同一次设置会话中启用。
- 透明度范围改为 `0…1`，步长保持 `0.05`；`0%` 表示 Island 背景完全透明，不隐藏文字、图标或可交互区域。
- 默认黑色下调整透明度时，设置规范化为 `{ kind: "solid", color: "#000000", opacity }`。
- `input` 事件即时更新百分比；最终值在 `change` 事件持久化，避免设置事件导致拖动中的 DOM 被替换。
- 背景图仍使用独立的遮罩强度，不把本次颜色透明度滑块误用于图片模式；禁用状态提供可读说明。

### 2. 自适应前景

渲染层根据规范化后的外观生成 `light`、`dark` 或 `glass` 三类前景配置，并通过根节点 CSS 变量统一下发：

- `--island-fg-primary`
- `--island-fg-secondary`
- `--island-fg-tertiary`
- `--island-control-fill`
- `--island-control-border`
- `--island-content-shadow`
- `--island-surface-shadow`

不透明纯色按背景相对亮度选择浅色或深色前景。渐变使用两个端点中对比风险更高的一端决定前景。图片背景与低透明度背景进入 `glass` 配置：采用浅色前景和克制的深色双层文字/图标阴影，在内容密集的控件上保留局部半透明衬底。这样不会重新盖回一整块黑色 Island，同时能应对未知深浅的壁纸。

背景为 `0%` 时移除 Island 外轮廓阴影，保留内容阴影和局部控件衬底。用户看到的是漂浮在桌面上的内容，而不是一个残留的黑色轮廓。

### 3. 系统性能圆环

性能圆环继续使用绿色、黄色和红色表达负载等级，但中心改为真正镂空：用 CSS mask 绘制环形，不再用伪元素覆盖一个固定底色。中心自然显示当前 Island 背景；全透明时显示桌面背景。

性能数值和剩余轨道使用语义前景变量，状态含义不只依赖颜色，现有数值文本继续保留。

## 数据流

1. 设置页产生颜色或透明度设置。
2. 主进程沿用现有 `normalizeIslandAppearance()` 验证并保存；透明度下限调整为 0。
3. Island 渲染器用同一外观对象生成背景 CSS 和前景 profile。
4. `applyIslandAppearance()` 在一次更新中写入背景、前景变量和 tone 标记，避免背景与文字短暂错配。

不新增用户设置字段，也不迁移现有配置。旧配置继续有效；默认外观仍为经典不透明黑色。

## 错误与回退

- 无效颜色继续由共享规范化层拒绝或回退。
- 图片读取失败继续回退到黑色背景，并同步采用浅色前景。
- 无法分类的外观采用经典黑底浅色字，不允许出现无背景且无可读性保护的状态。

## 测试与验收

- 单元测试先覆盖 `opacity: 0` 不被钳制、默认背景转换为可调黑色，以及 light/dark/glass profile 的边界。
- 渲染测试覆盖 `applyIslandAppearance()` 同时写入和清理背景、tone 与语义变量。
- 设置页源测试覆盖换色/选预设后重绘、0% 范围、键盘可访问标签和图片模式说明。
- CSS 测试确保性能环使用 mask 且不存在固定黑色中心，并确保关键文字/控件引用语义变量。
- 完整检查通过后，在真实设置窗口验证：换色后无需关闭即可拖动；0%、50%、100% 均能保存；浅色、深色和透明背景下折叠态、顶部工具栏及展开面板内容可辨认。

## 不在本次范围

- 屏幕采样、壁纸分析或新增屏幕录制权限。
- 背景图片透明度与图片编辑能力。
- 用户手动选择前景色或关闭可读性保护。
- 重做外观设置页整体布局。
