# 顶部快捷栏：保留自定义空位

用户确认：不再强制紧凑排列，首次安装开启所有顶部工作台模块（含剪贴板）。

- 默认沿用文件架、剪贴板、终端、用量、性能、桌宠顺序，先使用左侧安全区，再使用右侧安全区。主页、更多、设置保留固定入口。
- 拖到空位保存具体槽位；拖到已有按钮交换位置。来自更多的按钮占用目标位置，被替换按钮移到空位，没有空位则进入更多。
- 自定义位置以左右区域及槽位编号保存。屏幕变窄时不可用的位置临时进入更多，恢复空间后回到原位，不覆盖原偏好。
- 槽位不覆盖余额、实体摄像头、固定入口。右侧最后一格紧邻更多入口。
- 隐藏按钮保留其余按钮的位置。Esc、窗口失焦、拖出有效区域取消操作。
- 修正桌宠按钮沿用旧 24px 尺寸导致的偏移，统一为 32×30px。
- 剪贴板首次安装默认开启，历史仍只保存在本机，保留关闭与清空入口。升级保留已有的明确关闭设置。不额外开启歌词、告警等子选项。

此决定替代 2026-08-24 工作台设计中的“剪贴板默认关闭”，其余功能不变。
