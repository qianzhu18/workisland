# WorkIsland 媒体与性能工作台设计

## 目标

把 WorkIsland 从单一的智能体状态面板扩展为 macOS 灵动岛工作台，同时保留智能体监控作为核心能力。

第一阶段只加入两项能力：

- 系统当前媒体播放；
- CPU、内存与进程占用监控。

日历、GPU、磁盘、网络和其他 Atoll 功能不在本阶段范围内。

## 许可证边界

Atoll 使用 GPL-3.0，WorkIsland 使用 Apache-2.0。WorkIsland 可以研究并重新实现 Atoll 的产品行为和系统接口使用方式，但不得直接复制 Atoll 的 Swift 源码、二进制框架、图标、音频或其他受版权保护的素材。

本功能采用独立实现：

- 不复制 Atoll 源文件；
- 不引入 Atoll 的二进制产物；
- 使用 WorkIsland 自己的命名、数据协议、界面组件和测试；
- 在第三方声明中记录实际新增依赖；若没有新增依赖，则不增加 Atoll 代码归属声明。

## 产品交互

### 无媒体播放

展开后的整个灵动岛继续显示现有智能体任务。现有审批、回答、完成、错误和会话跳转行为保持不变。

### 有媒体播放

展开态自动切换为双栏：

- 左侧约 40% 为媒体区域；
- 右侧约 60% 为智能体任务区域；
- 当窗口宽度不足时，优先保证智能体操作按钮可用，媒体区域收缩到紧凑布局；
- 媒体会话结束后，左栏通过弹性动画收回，智能体区域恢复全宽。

媒体区域显示：

- 专辑封面或应用图标回退；
- 歌曲或媒体标题；
- 艺术家或来源应用；
- 当前进度和总时长；
- 上一首、播放或暂停、下一首；
- 点击封面或标题回到来源应用。

暂停时保留媒体区域，但降低封面、进度和文字亮度。系统不再报告有效媒体会话时，移除媒体区域。

### 收起态与短暂提醒

收起态继续以智能体状态为主。以下事件可形成类似 iPhone 灵动岛的短暂实时活动：

- 歌曲切换：短暂展示封面和标题，然后恢复原状态；
- 智能体完成：保持现有完成提醒；
- 审批、等待回答和任务错误：立即覆盖普通媒体提示；
- 持续性能异常：在达到阈值并持续一段时间后提醒一次。

提醒优先级从高到低为：审批或回答、错误、智能体完成、性能异常、歌曲切换、普通播放状态。高优先级提醒结束后恢复之前的双栏状态。

### 性能入口

灵动岛右上角新增性能按钮，与宠物、声音和设置按钮同级。

- 悬停：打开性能浮层；
- 点击：固定或取消固定浮层；
- 未固定时鼠标离开按钮和浮层后自动关闭；
- 浮层显示 CPU 使用率、内存使用量和比例、内存压力、占用最高的进程；
- 首版仅提示持续高 CPU 和高内存压力，所有提醒均有冷却时间，避免打扰。

## 技术架构

### 媒体桥接进程

新增 WorkIsland 自有的 macOS 原生辅助进程。它动态访问系统 Now Playing/MediaRemote 能力，监听系统当前媒体会话，因此不按 Apple Music、Spotify 或浏览器逐个硬编码。

辅助进程通过 JSON Lines 与 Electron 主进程通信：

- 向主进程推送媒体元数据、播放状态、进度、来源应用和封面；
- 接收上一首、播放、暂停、下一首和跳转来源应用命令；
- 系统接口不可用、返回字段缺失或媒体来源不支持某个控制命令时，降级而不影响智能体监控。

MediaRemote 属于 macOS 非公开系统接口，可能随系统版本变化。实现必须动态探测符号、隔离崩溃，并在不可用时隐藏媒体功能。WorkIsland 不因此阻塞启动。

### 性能采集服务

性能采集留在 Electron 主进程的独立服务中：

- 使用系统 CPU 时间差计算整体 CPU 使用率；
- 使用系统内存数据计算已用内存和比例；
- 使用 macOS 系统命令或原生信息读取内存压力；
- 仅在性能浮层打开或固定时采集进程排行，以降低常驻开销；
- 所有采集结果通过现有 preload IPC 白名单发送给渲染进程。

采集服务不得阻塞主线程。读取失败时保留上一个有效值，并在过期后展示不可用状态。

### 渲染层

在现有 IslandPanel 中增加三个隔离组件：

- `MediaCard`：只负责媒体展示和控制；
- `WorkspaceSplit`：只负责媒体与智能体区域的响应式布局；
- `PerformancePopover`：只负责性能摘要、排行和固定交互。

媒体状态、性能状态和智能体会话保持为三套独立数据，不改变现有智能体 session state 模型。

## 设置

设置中新增“工作台”区域：

- 显示媒体播放，默认开启；
- 歌曲切换时显示短暂提醒，默认开启；
- 显示性能监控，默认开启；
- 性能异常提醒，默认关闭。

关闭媒体或性能能力后，相关后台采集也应停止，而不仅是隐藏界面。

## 安全与隐私

- 媒体标题、艺术家、封面和性能数据只在本机处理；
- 不上传播放历史或进程列表；
- 日志不得记录完整媒体标题、封面数据或完整进程命令行；
- 不申请日历、通讯录、屏幕录制或辅助功能权限；
- 原生辅助进程仅接受 WorkIsland 主进程定义的有限控制命令。

## 测试与验收

### 自动化测试

- 媒体 JSON Lines 协议解析和异常输入；
- 无媒体、播放、暂停、切歌和媒体结束状态转换；
- 双栏与全宽布局判定；
- 智能体高优先级提醒覆盖媒体提醒并正确恢复；
- CPU 和内存计算；
- 性能排行仅在浮层活跃时采集；
- 设置关闭后停止对应采集；
- preload IPC 只暴露允许的方法。

### 本机验收

- Apple Music、Spotify 和浏览器媒体至少各验证一次；
- 验证播放、暂停、上一首、下一首和进度更新；
- 同时运行智能体任务，确认双栏不会遮挡审批和跳转；
- 停止媒体后确认智能体区域恢复全宽；
- 悬停和固定性能浮层，确认 CPU、内存和进程排行更新；
- 模拟媒体桥接进程不可用，确认 WorkIsland 与智能体监控仍正常；
- 检查空闲状态下的 CPU 与内存开销没有明显回归。

## 非目标

本阶段不实现日历、提醒事项、歌词、音频频谱、GPU、网络、磁盘、摄像头、剪贴板、计时器或第三方扩展系统，也不把 WorkIsland 改造成 Atoll 的分支或衍生发行版。
