# WorkIsland 工作台展开与记忆逻辑设计

## 目标

让智能体主页、文件架、剪贴板和终端遵循一致、可预期的灵动岛展开逻辑，同时严格区分：

- **展示位置**：下次展开先看到智能体主页还是上次工具。
- **工具数据**：文件架引用、剪贴板历史、终端进程与终端输出。

收缩灵动岛只能改变展示位置，不能删除文件架内容、清空剪贴板、停止终端或丢失终端输出。

## 默认交互

1. 鼠标进入胶囊后展开灵动岛。
2. 用户可在顶部工具栏切换智能体主页、文件架、剪贴板和终端。
3. 顶部工具栏在任一工具页都提供明确的“智能体主页”入口。
4. 普通页面在鼠标离开后延迟收缩；拖放文件、按住鼠标、编辑输入内容时避免误收缩。
5. 完整终端获得键盘焦点时，单纯移走鼠标不强制打断输入；点击其他应用导致窗口失焦时必须收缩，但后台终端继续运行。
6. 审批、提问、失败等需要注意的智能体事件始终切到智能体主页并展开。

## 再次展开设置

新增设置 `toolboxReopenMode`：

- `agent`：默认值。收缩后再次展开先显示智能体主页。
- `last`：再次展开回到用户上次主动选择的工具页；若工具已被关闭，则回到智能体主页。

该设置只控制视图选择，不影响任何工具数据或后台服务。

## 工具状态生命周期

### 文件架

- 文件引用继续由本地 ShelfService 持久化。
- 收缩、切换页面或重启界面均不删除文件。
- 只有用户点击“移除引用”或确认“清空”才改变数据。

### 剪贴板

- 历史记录继续由本地 ClipboardService 管理。
- 页面切换和收缩不清空历史。

### 终端

- 终端进程继续由主进程 TerminalService 管理。
- 收缩或切换到智能体主页只卸载可视终端组件，不停止 PTY。
- 再次打开终端时恢复当前工作目录、运行状态和最近输出。
- 停止终端只发生在用户显式关闭相关功能或应用退出时。

## 快捷命令

- 灵动岛只展示用户在设置中保存的快捷命令。
- 删除固定展示的“查看 Git 状态”和“运行项目测试”。
- 没有自定义命令时显示空状态，并提供进入设置的入口。
- 设置页说明以小字提供示例：`git status`、`npm test`、启动开发服务等；示例不会自动创建为命令。
- 主进程只允许执行设置中实际保存的命令，渲染层不能提交任意命令文本。

## 状态边界

- `activeModule`：当前正在显示的页面。
- `lastUtilityModule`：用户最后主动选择的有效工具页，仅供 `last` 模式恢复。
- `toolboxReopenMode`：决定新一轮展开的初始页面。
- 工具数据和进程不存放在上述展示状态中。

所有收缩入口（鼠标离开、窗口失焦、Esc、点击外部、打开设置）必须走同一收缩函数，由该函数根据 `toolboxReopenMode` 决定是否把视图重置为智能体主页。

## 验收标准

1. 默认模式下，从任一工具页收缩后再次展开均显示智能体主页。
2. “记住上次工具”模式下，再次展开恢复最后一个仍启用的工具。
3. 文件架内容、剪贴板历史和后台终端在两种模式下都不会因收缩而丢失。
4. 完整终端点击外部后可靠收缩，再次进入终端可看到仍在运行的会话与输出。
5. 任一工具页都能通过顶部按钮返回智能体主页。
6. 审批、提问和失败事件会覆盖工具页并显示智能体主页。
7. 默认不展示任何内置快捷命令；用户自定义命令可添加、执行和删除。
8. 文件拖入、文件拖出和选择文件后，窗口仍能正常接收鼠标。
