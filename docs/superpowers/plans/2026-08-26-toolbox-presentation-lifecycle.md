# WorkIsland Toolbox Presentation Lifecycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make toolbox panels collapse predictably, optionally restore the last tool, preserve all tool data and terminal processes, and show only user-defined terminal shortcuts.

**Architecture:** Keep file, clipboard, and terminal state in their existing main-process services. Add a normalized presentation-only setting and use the existing requested-toolbox-module event to choose the next visible page without changing service data. Route every collapse through the existing `collapsePanelToPill` callback and remove the toolbox-specific mouse-leave exemption.

**Tech Stack:** Electron 43, React runtime, Node test runner, shared CommonJS settings and ES module toolbox model.
