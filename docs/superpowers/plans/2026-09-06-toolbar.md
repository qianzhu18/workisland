# Top toolbar implementation plan

Goal: deliver Issue #69 camera-safe navigation and predictable pointer sorting.

Approved design: keep Agent Home and Settings fixed; remove sound from the toolbar and move session cleanup to the session list. Measure usable space outside the physical notch. Overflow tools into a labelled menu below the notch. Pointer sorting previews insertion, commits the current order on release and cancels outside or on Escape. Hidden tools can be promoted without moving the active navigation unexpectedly.

Architecture: a separate ToolbarTools component owns measurement, overflow and pointer lifecycle. The existing panel owns persisted module order and feature actions. Native display information supplies notch width; CSS grid reserves its space.

Tasks:
- Implement capacity and insertion model with behavioural tests for repeated moves and narrow layouts.
- Extract toolbar interaction into ToolbarTools.js; use pointer capture, preview slots, cancellation and click suppression.
- Wire camera width through app and panel; relocate cleanup, remove sound button, add menu and reduced-motion styles.
- Run repository checks, package macOS, install with recoverable backup and verify the installed build.

Validation: all enabled modules; narrow capacity; fixed home/settings; repeated left/right moves; Escape/outside cancellation; hidden module promotion; actual packaged runtime. Functional modules remain owned by their current components.

2026-09-07 follow-up: replace the one-bank capacity model with measured left/right slots and persist bank preferences. Allow all tools, including Performance and Pet, to drag between menu and either bank. Remove Performance pin state and retain delayed hover dismissal, outside dismissal and Escape. Expand the CDP smoke test to real pointer menu extraction, cross-camera moves, full capacity and a non-destructive process-selection fixture.
