# 额度与用量

顶部“额度与用量”插件将 Codex 订阅额度与本地 API/Agent 用量放在同一入口，可拖动排序、固定或收进“更多”。默认显示 Codex 首个有效窗口的剩余百分比，不再额外占用固定区域。

悬停片刻预览；点击固定，移入详情可继续阅读。点击关闭、外部区域、Escape 或关闭岛面板即可收回。详情展示两个 Codex 额度窗口及重置倒计时、近七天本地 Token 与估算费用，底部打开完整看板。

没有额度数据时保留按钮和破折号；请确认本机 Codex 登录。隔离测试目录没有登录数据，不代表真实账号额度丢失。Codex 显示开关关闭时不展示订阅数值，用量看板仍可按原开关使用。

本地用量包含记录到的订阅会话，不等于 API 服务商的真实账户余额；未定价的用量单独注明，不伪造余额或零费用。此功能没有新增账号认证或服务商余额 API。

升级时，原本开启的固定 Codex 额度会迁移为可见插件，即使旧的独立用量按钮在“更多”中；之后用户主动收纳会被保留。

验证：`npm run check`；源代码隔离预览启动后运行 `node scripts/smoke-usage-entry.mjs`。Smoke 对空额度真实状态、浮层交互、收纳/固定/拖动以及明确标注的额度布局夹具分别验收。夹具不代表真实账户读数。
