# 桌面终端模式（待验收）

WorkIsland 创建的终端可以留在灵动岛中，也可以各自在桌面窗口运行。两处使用同一个 Shell 和终端视图，移动时不会重新执行命令。

- **拖到桌面**：在终端列表或完整终端标题中，拖动抓手到灵动岛外松手；也可以点击「移到桌面」。
- **收回**：用桌面终端内容顶部的抓手拖到灵动岛胶囊或展开面板内松手，目标会高亮；也可以点击「收回灵动岛」。原生标题栏只负责普通窗口移动。
- **找回窗口**：终端列表标注「桌面窗口」，点击该条目会激活对应窗口。
- **关闭与结束**：关闭桌面窗口会收回终端；要结束任务，在列表中点击该终端的关闭按钮并确认。关闭 WorkIsland、关闭终端功能仍会结束其持有的任务。
- **取消拖动**：Escape、失焦或捕获中断会取消，桌面窗口恢复原位置。长时间未松手的拖动也会自动取消。
- **Agent 提醒**：查看岛内终端或聚焦桌面终端时，自动提醒不会切页或抢输入；待处理审批、提问和异常可在终端列表入口查看并主动进入。

普通 Terminal / iTerm2 窗口由原应用持有，不能直接无损拖入。现有外部终端列表仍可查找并回到原应用。本期没有接管任意外部 PTY，也没有引入 tmux。

终端视图在第一次打开时创建，未访问的终端不会预先创建页面。每个已打开的终端保有独立渲染进程，以保留输入、滚动、选区和 TUI 状态，多个终端会增加内存。关闭不再使用的终端会释放相应页面和任务。
