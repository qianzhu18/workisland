> ## ⚠️ 重要变更：匿名使用统计默认开启
>
> 自本版本起，WorkIsland 的匿名使用统计**默认开启**（此前为默认关闭 + 启动询问）。这是 2026-08-22 的产品决策，公开说明如下：
>
> - **收集什么**：事件类型（启动 / 会话开始与完成 / 审批处理 / 回源跳转 / 白名单设置项变更）、Agent 名称、动作与目标类型、App 与 macOS 版本、一串随机匿名编号。**绝不包含**对话记录、prompt、代码、文件路径、项目名、主机名、用户名或密钥。
> - **送去哪里**：PostHog（美国区），仅用于统计产品使用。事件清单开源可查（`src/shared/telemetry.cjs`）。
> - **如何关闭**：「设置 → 关于 → 允许匿名使用统计」，一键关闭立即生效并清空未上报数据。
> - **既往选择被尊重**：曾在旧版本中明确拒绝过的安装保持关闭，不会被本变更翻转。
> - 开发构建（未打包）从不上传。

## 匿名使用统计（PostHog）发布闭环

对应 Change：`docs/openspec/changes/2026-08-21-posthog-opt-in-telemetry/`（根目录）· [PRD-005](./product/prd/PRD-005-ANONYMOUS-TELEMETRY.md) · [遥测说明](./TELEMETRY.md)

### 用户可见行为

- **默认开启、设置内披露。** 新安装与从未做过选择的升级安装不弹同意窗口，匿名使用统计直接生效；「设置 → 关于」披露数据范围、目的地并提供一键开关。
- **只发送开源白名单**（`src/shared/telemetry.cjs`）中的事件与属性：事件类型、Agent 名称、动作、回源目标、白名单设置项的 key，以及随机匿名编号和 App/macOS 版本。绝不包含会话内容、代码、路径、项目名、主机名、用户名或密钥。
- **明确拒绝者保持关闭。** 曾在旧同意流程中记录过拒绝的安装不被迁移翻转。
- **关闭即真关闭。** 在「设置 → 关于 → 允许匿名使用统计」关闭的瞬间，本地未上报队列立即清空，之后不再产生任何遥测请求；开关状态跨重启持久。
- **本机可见发送状态。** 同一设置页显示待发送数量与最近一次 PostHog 批量接口的 HTTP 2xx 确认时间；它不上传额外字段，也不等同于 PostHog 后续分析处理完成。
- **开发构建从不上传**；出网只发生在打包应用的主进程。

### 本轮加固（相对上一内测构建）

- 白名单改为对**事件名**也失败安全：`EVENTS` 之外的事件名在入队前即被拒绝，不再只是丢弃属性。
- 启动加载 `pending.json` / `state.json` 时逐条重新校验并再次清洗：旧版本残留、已下线事件或被篡改的队列条目不会在下次 flush 时离开设备。
- 同意模式从"启动询问 + 默认关闭"改为"默认开启 + 设置披露"（见顶部重要变更）。

### 验证状态

- 单元 / 静态检查：`npm run test:unit`、`npm run check`（含新政策迁移、明确拒绝保留、开关持久化、未知事件拒绝、持久化队列再校验、关闭清队列、开发模式不出网）。待实跑确认后勾选。
- 打包应用（macOS arm64）端到端（2026-08-21 在 opt-in 版本上完成）：未开启无任何 PostHog 连接；开启后最小事件 `app_launched` 送达并清队列；真实设置开关关闭后队列立即清空且整个 flush 周期无新请求。默认开启版待同流程复验。证据见 Change `evidence.md`。
