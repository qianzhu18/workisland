## 匿名使用统计（PostHog，opt-in）发布闭环

对应 Change：`docs/openspec/changes/2026-08-21-posthog-opt-in-telemetry/`（根目录）· [PRD-005](./product/prd/PRD-005-ANONYMOUS-TELEMETRY.md) · [遥测说明](../TELEMETRY.md 的仓库内副本)

### 用户可见行为

- **默认关闭。** 新安装与未记录当前版本选择的升级安装均不发送任何遥测；欢迎页勾选框默认不勾选，升级安装显示一次性独立隐私选择窗口。
- **未选择不算同意。** 关闭选择窗口不记录任何决定，下次启动再次询问。
- **明确同意后才发送**，且只发送开源白名单（`src/shared/telemetry.cjs`）中的事件与属性：事件类型、Agent 名称、动作、回源目标、白名单设置项的 key，以及随机匿名编号和 App/macOS 版本。绝不包含会话内容、代码、路径、项目名、主机名、用户名或密钥。
- **关闭即真关闭。** 在「设置 → 关于 → 允许匿名使用统计」关闭的瞬间，本地未上报队列立即清空，之后不再产生任何遥测请求。
- **开发构建从不上传**；仅打包应用且明确同意后才可能出网，出网只发生在主进程。

### 本轮加固（相对上一内测构建）

- 白名单改为对**事件名**也失败安全：`EVENTS` 之外的事件名在入队前即被拒绝，不再只是丢弃属性。
- 启动加载 `pending.json` / `state.json` 时逐条重新校验并再次清洗：旧版本残留、已下线事件或被篡改的队列条目不会在下次 flush 时离开设备。
