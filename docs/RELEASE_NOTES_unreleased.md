## Island 显示模式：极简 / 常驻

- 设置页中原「通知模式」「没有会话时隐藏」两个否定式开关收敛为一个正向选择：**Island 显示模式**。
  - **极简（新安装默认）**：没有待办事项或重要提醒时，Island 不占用可见顶部空间；仍可通过顶部透明热区、菜单或快捷键（默认 `Ctrl+I`）唤回。
  - **常驻**：空闲时保留紧凑胶囊；普通后台运行不会长期展开面板。
- 两种模式下：任务提交与完成短暂显示（时长由「完成通知停留时间」控制）；审批、提问和错误持续显示，不会被自动隐藏计时器收起。
- 旧版本中「通知模式」「没有会话时隐藏」偏好会在首次启动新版本时一次性迁移（详见 Change `evidence.md` 迁移映射）；已显式选择常驻胶囊的用户保持常驻，之后显示行为只由新模式字段决定。
