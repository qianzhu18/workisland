## 七、流转纪律（所有协作者共用）

1. **需求池**（飞书）= 想法与证据，未排期不动工
2. **GitHub Issue**（打 `status: ready`）= 可认领的交付待办；PR 描述写 `Closes #x`，合并自动销账
3. **规划文档**（本文件）= 版本范围基线，改范围先改这里
4. 完成后飞书任务卡回写状态；"已交付"口径 = 用户手上能用（发版为准），代码合 main 不算
