# WorkIsland Product Vision

状态：`active`

## 愿景

WorkIsland 成为本地优先的工作注意力路由器：当用户同时运行多个 AI Agent 和异步工作任务时，不必反复寻找窗口，也能知道什么需要处理，并安全回到正确上下文。

## 初期用户与问题

初期服务 macOS 上高频使用 Claude Code、Codex、Cursor 和同类 Agent 的个人工作者。他们会同时运行多个会话，容易错过审批、问题或完成结果，并被迫在终端、IDE、显示器和应用窗口之间反复切换。

## 核心价值

- 看得见：低干扰地汇总真实任务状态。
- 叫得回：只在需要用户处理时提醒。
- 接得上：尽可能回到正确的终端、IDE 或会话。
- 本地优先：会话内容、代码、路径和身份默认留在用户的 Mac 上。

## 产品边界

WorkIsland 不生成工作内容，不伪造 Agent 状态，也不依赖云端账户。匿名使用统计默认开启，在「设置 → 关于」公开披露并可随时关闭；它只上报受白名单限制的匿名事件，关闭会清空未发送队列，详见 [PRD-005](./prd/PRD-005-ANONYMOUS-TELEMETRY.md)。

## 当前成功证据

- 新用户在 5 分钟内看到真实 Agent 信号。
- 用户能够理解提醒、完成处理并回到正确上下文。
- Pilot 的激活率达到 70%，D7 留存达到 40%，活跃日人均回源达到 1 次。
