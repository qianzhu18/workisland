# EPIC-008: Skin UGC Marketplace

状态：`draft`
目标阶段：`v0.4.x`
来源：用户提出的像素 Logo、皮肤商店和 AI 辅助创作场景

## 1. 产品假设

WorkIsland 的角色/Logo 是高频可见的身份表达。用户愿意上传自己的像素角色或品牌图，并通过社区浏览、安装和反馈，前提是素材导入足够简单、默认素材始终可用、发布过程有审核和撤回机制。

## 2. 分阶段边界

### Phase A：本地皮肤包（先验证需求）

- 定义版本化 `skin.json` manifest 和 PNG/WebP 资源约束。
- 设置页支持导入、预览、启用、禁用和恢复默认。
- 不联网、不收款、不把本地路径或 Agent 会话上传。

### Phase B：创作工具协议

- 提供 CLI 和 MCP 两种等价入口：读取模板、生成资源、校验 manifest、导出 zip。
- AI 只能写入用户指定的工作目录；发布前由用户明确选择上传素材。
- 生成结果必须经过尺寸、透明度、动画帧数、文件大小和许可证字段校验。

### Phase C：社区商店

- 用户提交草稿，服务端病毒扫描、版权/品牌声明和人工/规则审核后才公开。
- 支持版本、作者、许可证、举报、撤回和兼容性标签。
- 初期只做免费分享和安装统计，不引入交易、积分或推荐分成。

## 3. 成功门槛

- Phase A：至少 5 名用户成功导入自制皮肤，且无默认皮肤回退失败。
- Phase B：至少 3 个不同 AI 客户端通过 MCP/CLI 完成一次合规导出。
- Phase C：首批 20 个公开皮肤中 0 个包含会话内容、密钥或未授权第三方素材。

## 4. 主要风险

- 版权和品牌冒用：强制许可证/来源字段、举报和下架流程。
- 恶意资源：上传隔离、MIME/魔数检查、尺寸与解码限制、签名下载包。
- AI 生成内容不稳定：模板化 schema、预览隔离和用户确认，不允许直接覆盖当前皮肤。
