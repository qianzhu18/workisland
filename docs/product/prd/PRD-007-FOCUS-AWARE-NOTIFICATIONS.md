# PRD-007: Focus-Aware Notifications

状态：`in-progress`
目标版本：`v0.3.0-beta.2`
父 Epic：[EPIC-007](../epics/EPIC-007-FOCUS-AWARE-NOTIFICATIONS.md)

## 1. 用户结果

当用户提交一个 Agent 任务或任务完成时，WorkIsland 在顶部短暂展示对应会话；除此之外不占据屏幕空间。需要用户决策的审批、提问和错误仍然持续可见。

## 2. 行为规格

| 事件 | 展示 | 默认时长 | 结束状态 |
| --- | --- | --- | --- |
| 新 prompt 提交 | 仅对应会话的 Island 面板 | 5 秒 | 隐藏到透明热区 |
| 正常完成 | 仅对应会话的 Island 面板 | 5 秒 | 隐藏到透明热区 |
| 审批/提问 | 对应会话的可操作面板 | 不自动隐藏 | 用户处理后收起 |
| 错误完成 | 对应会话的错误面板 | 不自动隐藏 | 用户查看/关闭后收起 |
| 普通运行中更新 | 不自动弹出 | - | 只更新状态 |

## 3. 设置

- `通知模式`：默认开启；关闭后恢复常驻 Island 胶囊。
- `任务提交时展开`：默认开启；关闭后只保留完成和阻断式提醒。
- `任务完成时展开`：沿用现有开关。
- `完成通知停留时间`：沿用现有 5/10/20/30 秒选项，默认 5 秒，同时影响提交通知。

## 4. 验收标准

- 启动后无活动通知时窗口透明，鼠标移到顶部仍能唤回。
- 带有效 `latestUserPrompt` 的提交事件只触发一次通知；hook 和 transcript 双通道重复上报不重复弹出。
- 完成事件只触发一次通知；通知倒计时不因 session 更新而重置。
- 5 秒后 renderer 清理 surface，并通过 `surfaceDismissed` 让主进程恢复隐藏状态。
- 审批/提问不会因为默认通知模式被隐藏，也不会被 5 秒计时器自动关闭。
- 关闭 `通知模式` 后，原有悬停和点击展开行为保持不变。

## 5. 技术边界

提交通知从 `sessionStarted` 或带 `latestUserPrompt` 的 `activityUpdated` 事件识别；启动发现路径只直接恢复状态，不发送通知。通知策略与窗口隐藏逻辑分离，避免 renderer 更新会话时重置计时器。
