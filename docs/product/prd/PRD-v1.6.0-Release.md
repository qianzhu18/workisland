# Version PRD: v1.6.0

状态：`release-candidate`  
目标版本：`v1.6.0`  
GitHub tracking Issue：[193](https://github.com/qianzhu18/workisland/issues/193)

## 1. 版本一句话

将 v1.5.1 以后已合并的会话搜索、自动接入、系统状态与性能修复交付现有 macOS 用户。

## 2. 目标与范围

1. 更快找到历史会话并回到原客户端（#176–#183）。
2. 减少接入维护与资源峰值（#184、#186–#188、#191）。
3. 顶部工具栏呈现系统状态，提示避开摄像头且不抢占 Agent 待处理（#192）；恢复固定 Codex 额度、独立收纳用量看板（#195）。

未合并的双向交接 #189、Windows 新发行与新遥测不在本版。历史 PRD 编号存在跨分支引用，本版使用版本名文件避免复用已有编号。

## 3. 任务与验收

| 任务 | 完成证据 |
| --- | --- |
| 版本与发布文案 | package/lock 1.6.0、双语 Release Notes、官网 changelog 与 guide |
| 自动回归 | npm run check、release:check、四项 PR CI |
| 候选包 | 隔离用户目录启动、Agent 事件、设置持久化、旧安装与数据保留 |
| 正式分发 | Actions arm64/x64 签名、公证、Staple、Gatekeeper、SHA-256、latest |

## 4. 数据与学习

沿用现有匿名统计与问题反馈，不新增采集。发布后通过版本号与用户反馈观察启动、更新和回源故障；任何可复现启动失败、数据丢失或更新安装失败优先修复。24 小时和 7 天复盘由维护者记录，不自动创建提醒。

## 5. 发布物料与验证边界

中文全文与 English Summary 在 docs/RELEASE_NOTES_UNRELEASED.md；CHANGELOG.md、官网 /changelog/、/guide/ 同步。用户可在顶部更新入口或设置中选择安装。

本次原生状态已有真实录屏、刘海布局与用户视觉反馈。真实耳机切换、Wi-Fi 断开恢复、多屏休眠与真实锁定/解锁尚未完整验收，公开说明限制。锁屏信息默认关闭，不将预览视为真锁屏证据。
