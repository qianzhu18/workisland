# Optional Atoll presentation for WorkIsland

Atoll users should be able to see which local Agent needs attention, read a finished task’s result, and act without keeping two permanent islands visible.

WorkIsland owns session collection, usage data and approval routing. The user chooses a presentation target. In Atoll mode the provider registers a compact tab and live activity; the existing WorkIsland panel supplies richer interactions. No change to Atoll source is required. The default WorkIsland experience and non-macOS platforms must not start the bridge.

Acceptance: opt in and opt out; handle host reconnect and revocation; render only real available session and quota data; deduplicate notifications; display the request or result text; restore the native window when leaving Atoll mode. Official distribution and Marketplace review are separate from merging the integration.
