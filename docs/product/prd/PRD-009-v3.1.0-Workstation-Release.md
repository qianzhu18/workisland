# PRD-009: v3.1.0 Workstation Release

状态：`release-candidate`  
目标版本：`v3.1.0`  
关联 Feature PRD / Epic：Media Workstation、Productivity Toolbox、Codex lifecycle audio、Echo pet director  
GitHub tracking Issue：由 `release/v3.1.0` 发布 PR 承载

## 1. 版本一句话

让已经使用多个 AI Agent 的 macOS 用户，在同一个本地 Workstation 里更快看到媒体、文件、剪贴板、终端和桌宠状态，并通过一份公开 Changelog 理解每次更新带来的用户价值。

## 2. 背景、目标与非目标

- 当前证据：竞品研究显示，Agent-first 产品的差异不在简单功能数量，而在生命周期准确性、减少 Context Switching 和持续分发；main 已合入 Workstation、媒体同步歌词、Codex 声音和 Echo 导演层。
- 版本目标：交付可安装的 macOS Apple Silicon 包；把 main 上已完成的 Workstation 能力整理成用户可读的版本说明；建立根目录与官网双入口 Changelog。
- 非目标：Windows Alpha、dock 附件、token 统计、云端账户、移动端控制和新的通用 Widget。

## 3. 用户故事与范围

| 用户故事 | 需求 | 优先级 | 完成证据 |
| --- | --- | --- | --- |
| 作为多 Agent 用户 | 我希望在媒体、文件、剪贴板和终端之间切换时仍保持当前工作流上下文 | P1 | 工具箱、Media、Shelf、Clipboard、Terminal 测试通过；本机 DMG 抽查 |
| 作为 Codex 用户 | 我希望任务开始、完成或失败时得到一次可靠提示，而不是重复声音 | P0 | 生命周期声音和 Hook/转录去重测试 |
