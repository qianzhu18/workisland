# PRD-011：v3.2.0 macOS Template & Appearance Release

状态：`draft`
目标版本：`v3.2.0-rc.1` → `v3.2.0`
平台：macOS Apple Silicon
关联能力：本机 AI 外观自定义、外观模板系统、WorkIsland CLI
GitHub tracking Issue：待创建；发布分支为 `release/macos-v3.2.0-rc.1`

## 1. 版本一句话

让已使用 WorkIsland 的 macOS 用户可以安全地通过设置页或本机 Agent 更换 Island 外观、桌宠和状态模板，并在不联网、不暴露 Agent 会话内容的前提下恢复官方样式。

## 2. 背景、目标与非目标

### 当前证据

- 已发布 macOS 正式线为 `v3.1.0`；Windows MVP 的 `v1.0.0-alpha.*` 是独立内测线，不能用于 macOS 安装包命名。
- 候选代码包含本机外观 API、模板包校验/安装/恢复、设置页模板选择和 `workisland-cli template` 命令组，并为核心边界补充自动化测试。
- 当前发布 workflow 需要在正式打 Tag 前加平台门禁，保证 Windows Alpha Tag 不触发 macOS Release，反之亦然。

### 版本目标

1. 交付 `v3.2.0-rc.1` macOS Apple Silicon 受邀验证包，并且包内版本、PRD、Release Notes 与产物名完全一致。
2. 验证用户可从设置页完成模板选择、恢复官方模板和外观重置；本机 Agent 可调用受限 CLI 改变外观而不打开网络端口。
3. 通过 RC 验收后发布 `v3.2.0`，由签名、公证且 Staple 的 DMG 进入稳定更新通道。

### 非目标

- 不把 Windows `v1.0.0-alpha.*` 打包、改名或附带进本次 macOS Release。
- 不开放模板运行时的任意远程脚本执行、任意下载域名或云端账户同步。
- 不在 RC 阶段成为 GitHub `releases/latest`，不承诺自动更新。

## 3. 用户故事与范围

| 用户故事 | 需求 | 优先级 | 完成证据 |
| --- | --- | --- | --- |
| 作为 macOS 用户 | 我希望从设置页选择或恢复外观模板，而无需理解文件结构 | P0 | 真机录屏/截图；模板切换、重启后保留、恢复官方模板均成功 |
| 作为 Agent 使用者 | 我希望本机 Agent 能预览并在确认后应用外观，不将会话或模板内容上传 | P0 | CLI 与 bridge 测试；网络监听检查；用户确认流程走查 |
| 作为安全敏感用户 | 我希望损坏模板不会破坏 Island，并能自动回退 | P0 | manifest、哈希、SVG 安检与回退测试通过 |
| 作为下载者 | 我希望版本、平台和安装包名称一致，知道自己安装的是 RC 还是稳定版 | P1 | PRD、Release Notes、CHANGELOG、Tag 与 DMG 文件名核对记录 |

## 6. 用户手册与发布物料

- 用户手册：补充「设置 → 外观模板」和本机 CLI 的确认边界，链接 `docs/AI-CUSTOMIZATION.md`。
- 官网与应用内入口：RC 仅指向受邀测试下载页；稳定版才更新 GitHub Releases 与官网主下载入口。
- Release Notes：`docs/RELEASE_NOTES_UNRELEASED.md` 以 `v3.2.0-rc.1` 为唯一候选版本。
- 已知限制：RC 未签名本地构建仅供验证；公开包必须通过 GitHub Actions 签名/公证。Windows Alpha 另见 PRD-010。

- [ ] `release.yml` 平台 Tag 门禁通过 CI 审查。
