# PRD-006: v0.3.0 Beta Pilot

状态：`in-progress`  
目标版本：`v0.3.0-beta.1`  
优先级：`P0`  
关联：[PRD-005](./PRD-005-ANONYMOUS-TELEMETRY.md)、[Release Process](../../RELEASE_PROCESS.md)

## 1. 版本一句话

向 5-8 名重度 macOS Agent 用户分发可复现的 Pilot 包，验证他们能否在真实多会话工作流里完成“看到状态、处理提醒、回到正确会话”的闭环。

## 2. 目标与非目标

目标：默认关闭且可审计的匿名统计；可用的手册和反馈入口；受邀 Beta 不进入稳定更新通道。

非目标：新 Agent 适配、付费墙、公开大规模推广、自动更新 Beta、会话或身份数据收集。

## 3. 交付范围

| 用户故事 | 需求 | 验收证据 |
| --- | --- | --- |
| 内测用户 | 能安装、连接 Agent、理解状态并反馈 | 手册、设置页入口、真实设备验证 |
| 内测用户 | 能自主决定是否启用匿名统计 | 首启默认关闭、设置开关、隐私测试 |
| 产品团队 | 能验证激活、留存和回源 | PostHog Insights 与访谈记录 |
| 发布维护者 | 不会把 Beta 推给稳定用户 | Pre-release、Tag 和包版本一致 |

## 4. GitHub Task 拆分

| 任务 | 类型 | 完成定义 |
| --- | --- | --- |
| 修正历史 `v0.2.8-beta.7/8` Release 类型 | 运营 | 两者均为 GitHub Pre-release |

## 5. 数据与学习

| 问题 | 证据 | 门槛 |
| --- | --- | --- |
| 首次价值是否形成 | `app_launched -> first_agent_signal` | 激活率 >= 70% |
| 用户是否持续受益 | D7 任意事件回访 | D7 >= 40% |
| 回源是否是核心价值 | `jump_back` / 活跃用户 / 天 | >= 1 |
| 目标画像是否正确 | 真实多 Agent 场景访谈 | 10 场中至少 7 场存在高频痛点 |
