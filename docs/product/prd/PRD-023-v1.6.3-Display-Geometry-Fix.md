# Version PRD: v1.6.3 Display Geometry Fix

状态：`released`  
目标版本：`v1.6.3`  
关联 Feature PRD / Epic：无  
GitHub tracking Issue：用户反馈截图，暂无公开 Issue

## 1. 版本一句话

让在特定显示配置下启动报错的用户能够正常收起灵动岛，同时向当前主分支用户提供已合并的最新功能。

## 2. 背景、目标与非目标

- 当前证据：国外用户截图显示 `TypeError: Error processing argument at index 1, conversion failure from`，堆栈指向 `windows.cjs` 的 `BrowserWindow.setSize(width, closedHeight)`。本机 Electron 43.3.0 用小数或 `NaN` 可复现同一报错。
- 版本目标：窗口尺寸始终为合法正整数；复用 GitHub Actions 完成签名、公证、Staple 与校验；官网与 GitHub 提供可下载的新版。
- 非目标：不声称已获得反馈用户设备的最终验收；不改变稳定更新通道；不新开 RC 或 1.7 版本线。
