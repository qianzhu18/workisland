## 1. 版本一句话

这个版本要让哪类用户在什么场景下，完成哪一个可验证的改变。

## 2. 背景、目标与非目标

- 当前证据：用户反馈、行为数据或已知风险。
- 版本目标：最多三个，必须可验收。
- 非目标：本版本明确不做的功能、渠道或商业动作。

## 7. 发布门槛与回滚

- [ ] `package.json`、lockfile 和 Git Tag 版本一致。
- [ ] P0 验收、自动检查和真实设备验证完成。
- [ ] Beta 为 GitHub Pre-release；稳定版才进入 `releases/latest`。
- [ ] 手册、反馈入口、DMG、签名/公证、SHA-256 已确认。
- 回滚方式：发布新的修复版本；不复用已推送 Tag。

## 8. 发布后复盘
