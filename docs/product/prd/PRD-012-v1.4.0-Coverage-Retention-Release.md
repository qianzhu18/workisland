## 1. 版本一句话

让已接入 Agent 的用户获得可控制的提醒节奏（安静时段）、更可读的 Plan 确认卡与更完整的用量口径；让开发者和国际用户拿到可编程入口与双语 Release 说明。

## 2. 背景、目标与非目标

- 当前证据：竞品对标（Ping Island 分发组合 = Trending + Cask + 双语 notes；Vibe Island 以 Markdown Plan 卡和性能数据做口碑）；main 已积压 4 个未发版特性，交付口径 = 发版。
- 版本目标：①四个已合特性正式发布；②Release 侧中英双语流程落地且不回退；③首次公开闲置性能实测数据（CPU < 3% 达标）。
- 非目标：#109 无刘海悬浮条、#110 i18n、#111 会话/tab 级抑制、#112 tab 级跳转明确顺延 v1.5+；Windows alpha 走独立版本线不占本版；不做 Product Hunt/HN。
