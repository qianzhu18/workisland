## 状态与命名

- 状态只能使用：`draft`、`ready`、`in-progress`、`validated`、`deprecated`。
- Epic：`EPIC-编号-主题.md`。
- Feature PRD：`PRD-编号-主题.md`。
- Version PRD：`PRD-编号-vX.Y.Z-主题.md`。
- 研究和发布复盘：`YYYY-MM-DD-主题.md`。
