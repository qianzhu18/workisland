# v1.6.0 Release Validation

范围：v1.5.1 到已合并的 #192、#195，包含会话搜索/回源、DSH 自动接入、内存优化、原生系统状态及固定 Codex 额度恢复。已关闭的合并额度试验 #194 和未合并的交接 #189 不包含在本版。

## 代码与候选包

- 698 项 Node 测试、源码与双语检查通过；#195 的 source-contracts、native-macos、windows-x64、windows-smoke 全部通过。
- `release:check -- --tag v1.6.0` 通过，package.json/lock 版本一致。
- Apple Silicon 未公证候选包安装后已启动：Codex 本地图标成功加载，固定左侧周期/已用百分比/倒计时与真实额度一致，位于摄像头安全区。
- 用量看板作为独立插件在“更多”中，可固定/收纳；不改变 Codex 固定区。
- 设置页真实控件对电池、网络、音频、屏幕捕获、下载、锁屏六项开关分别生效并保存；锁屏默认关闭。实际无声录屏两次验证：关闭捕获时不报告 active；开启时报告 active。临时视频已删除。
- 原生 helper、许可和 Codex 图标在候选包中存在；正式 workflow 对同一资源做打包守卫。
- 实际 Agent Hook 启动/结束事件 smoke 通过。
- 本机旧安装和用户数据保留备份，候选包未覆盖用户数据；正式包安装后继续核验签名、版本与主要 UI。

## 正式流水线门槛

正式分发只由 v1.6.0 Tag 触发；arm64/x64 两个 DMG 均需 Developer ID 签名、Apple 公证/Staple、Gatekeeper 和 SHA-256 成功。官网条目在 Tag 存在后合并部署。Release Notes 使用中文全文加 English Summary。GitHub Releases 为下载事实来源。

真实耳机连接/播放切换、Wi-Fi 断开恢复、多屏休眠和实际锁定/解锁仍需更多设备覆盖；不把布局夹具、原生预览或模拟状态当作这些场景的验收。锁屏功能默认关闭，用户可以关闭每项系统检测。

## 更新与回滚

现有用户保持自动检查设置时，启动后检查并每 24 小时检查稳定版；用户点击后才下载、校验、安装并重启，不静默替换。失败时提供手动 DMG 路径。保留 v1.5.1 下载；不覆盖既有 Tag，P0 用新修复版回滚行为。
