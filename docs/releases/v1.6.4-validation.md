# v1.6.4 自动更新稳定性修复

状态：发布候选，尚未发布安装包。

## 本次变更

- 更新检测、校验清单和安装包请求改用 Electron 网络栈，遵循 macOS 系统代理与 PAC。
- 检测和元数据请求增加超时及有限重试；失败不再触发 24 小时成功缓存冷却，短暂退避后可自动恢复。
- 并发检测及下载合并为同一操作，避免重复点击造成重复请求。
- 下载前获取校验清单；下载支持请求超时、流空闲超时、严格 Range 校验和跨重试/重启的断点续传。
- 续传进度绑定下载地址、文件大小及 SHA-256，完成后仍须通过完整校验。
- macOS 发布流程等待两个架构构建完成，验证安装包及校验清单后统一从草稿发布，避免不完整版本提前可见。

## 已有验证

- 修复分支已通过源码、国际化、静态检查及全量单元测试。
- 已在本机通过真实 Electron 网络栈访问 GitHub：版本接口 HTTP 200、统一校验清单 HTTP 200、DMG 单字节 Range 请求 HTTP 206。
- 此网络冒烟未下载完整安装包，不能替代打包后的真实升级验收。

## 发布前验收

- 对签名安装包完成旧版升级至 1.6.4 的端到端验收，覆盖 Apple Silicon 与 Intel。
- 验证下载中断、重启续传、代理及直连、安装失败后的手动安装回退。
- 已安装旧版的更新器不会随源码合入即时改变；如旧版自动下载失败，需手动安装 1.6.4 才能获得修复。
