Work stays where it happens. You return only when needed.

WorkIsland does not replace your agent, terminal, or other work apps. It starts with AI coding workflows, making the state, context, and next action visible when work needs you.

It supports first-party adapters for Claude Code, Codex, Cursor, TraeCode, ZCode, WorkBuddy / CodeBuddy, OpenCode, Kimi Code, Gemini CLI, GitHub Copilot CLI, Hermes, Aiden, DeepSeek Harness, and TRAE CLI.

What stays local

  • Agent sessions, project files, code, paths, host names, and user names stay on your Mac.
  • No cloud account is required to start monitoring a local workflow.
  • Anonymous product telemetry can be turned off at any time in Settings → About.

FAQ

Before you install

Is WorkIsland a notification manager or another task dashboard?

No. WorkIsland is a native Mac work interface for AI workflows: it makes work that needs you visible with the context and next action. The public release starts with coding agents; email, calendar, and general notifications are not advertised as shipped features.

Does WorkIsland replace Claude Code, Codex, or my terminal?

No. It works alongside the tools you already run and helps you return to the originating session when work requires you.

Which Mac systems can run WorkIsland?

Current public releases provide macOS builds for Apple Silicon and Intel Macs. See the official releases for the current installers and notes.

Is WorkIsland free?

Yes. WorkIsland is free and open source under the Apache 2.0 license. Download the current installer from the official GitHub Releases page.

Where can I ask for an agent integration or report an issue?

Open an issue with your WorkIsland version, the agent you use, steps to reproduce, and redacted diagnostics when relevant. That makes compatibility requests and bug reports actionable.
