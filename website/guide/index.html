USER GUIDE

WorkIsland 使用手册：
连接第一个 Agent 任务。

从安装到第一次回源，用一条真实任务确认 WorkIsland 是否适合你的工作流。

开始使用 ↓

QUICK START

从安装到第一个真实信号

  1. 01

    安装应用

    从官方 GitHub Release 下载 Apple Silicon DMG，将 WorkIsland 拖入“应用程序”。测试版如被 macOS 拦截，请只确认来源为官方 Release 后再按系统提示处理。

  2. 02

    检查 Agent 连接

    打开设置中的 Agent 页面，选择你已经在使用的 Agent，并按页面提示完成本地连接。没有连接成功时，应用不会伪造任务状态。

  3. 03

    开始第一个任务

    在已连接的 Agent 中运行一个真实任务。任务运行、等待处理或完成时，观察屏幕顶部的 Island；需要时点击相应任务回到原来的终端或应用。

SETTINGS

按你的工作方式调整

显示器、声音、触感、完成提醒和桌宠都在设置中。先维持默认配置，等完成几个真实任务后，再决定哪些提醒应当更主动或更安静。

多显示器

可以让 Island 跟随你正在使用的应用所在显示器，或固定到某块屏幕。

回源

支持精确回源的 Agent 会回到对应会话；无法精确定位时，应用会展示可用的后备路径。

桌宠

桌宠与 Island 使用同一份任务状态，切换显示方式不会停止监控。

LOCAL FIRST

你的会话留在 Mac 上

WorkIsland 不需要云端账户。会话内容、代码、路径、项目名、主机名和用户名不会被上传。

匿名统计默认开启

数据范围和关闭方式会在设置 → 关于中公开说明；不开启或关闭统计都不影响产品功能。

随时由你关闭

可在设置 → 关于中随时关闭。关闭会立即清空尚未上报的数据；旧版本中已明确拒绝的选择会被保留。

只看必要信号

只统计匿名事件类型、Agent 类型和应用版本，用于改善激活、留存与回源体验；不会上传会话内容、代码或路径。

SUPPORT

遇到问题，带上真实上下文。
