# WorkIsland 快速开始

> 用一条真实任务确认 WorkIsland 是否适合你的工作流。

## 1. 安装应用

从[官方 GitHub Release](https://github.com/qianzhu18/workisland/releases)下载适用于 Mac 的安装包，将 WorkIsland 放入“应用程序”并打开。确认下载来源为官方 Release 后，再按 macOS 提示完成打开。

## 2. 连接已经在用的 Agent

打开设置中的 Agent 页面，选择你已经使用的 Agent，并按页面提示完成本地连接。连接未完成时，WorkIsland 不会伪造任务状态。

## 3. 用一条真实任务验证

在已连接 Agent 中运行一条真实任务。观察 Island：任务运行时显示状态；需要处理时显示审批或提问；完成时可查看结果或跳回对应上下文。点击任务可回到原来的终端或应用。

## 调整和隐私

- 可在设置中调整显示器、声音、触感、完成提醒和桌宠；先完成几个真实任务，再决定需要哪些提醒。
- 支持精确回源的 Agent 会回到对应会话；不能精确定位时会展示后备路径。
- WorkIsland 不需要云端账户。会话内容、代码、路径、项目名、主机名和用户名不会上传。

## 需要帮助

反馈时附上应用版本、复现步骤、预期和实际结果，以及必要的脱敏截图或诊断日志。
