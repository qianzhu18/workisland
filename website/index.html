05 · 常见问题

下载前，先了解这些。

WorkIsland 支持哪些 Mac？+

当前安装包面向 Apple Silicon Mac（M 系列芯片），运行在 macOS 上。

我的会话内容会被上传吗？+

不会。WorkIsland 是本地优先应用，不上传会话内容、项目内容或使用数据。官网只提供产品信息与官方下载入口。

更新是怎么工作的？+

应用会定期检查官方稳定版信息，也可以在设置中手动检查。发现新版本时提醒你，下载仍从官方 Release 入口完成。

首次打开遇到系统提示怎么办？+

正式版本会由 GitHub Actions 自动签名并完成 Apple 公证。请只从官方 Release 或官网的官方下载按钮获取安装包。
