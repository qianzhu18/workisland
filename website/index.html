04 · 常见问题

下载前，先了解这几件事。

WorkIsland 支持哪些 Mac？

当前安装包面向 Apple Silicon Mac（M 系列芯片）。应用依赖 macOS 的灵动岛区域与本地原生窗口能力。

我的会话内容会被上传吗？

不会。WorkIsland 是本地优先应用，不上传会话内容、项目内容或使用数据。官网只负责提供产品信息和 Release 下载入口。

首次打开遇到系统提示怎么办？

优先使用签名、公证后的正式包。测试版如果被 macOS 拦截，请查看仓库 README 中的本机测试说明，不要从第三方网站下载修改过的安装包。
