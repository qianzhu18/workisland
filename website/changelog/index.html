CHANGELOG

每一次变化，
都应该值得被看见。

这里记录 WorkIsland 对真实工作流有意义的功能、修复和体验变化。提交历史属于工程，更新日志属于使用者。

LATEST STABLE 2026-08-28

v3.1.0

让 Media、工具箱、声音和桌宠都更贴近同一个 Agent 工作流。

新增

  • 同步歌词与专辑封面动效。
  • Shelf 文件架、私有剪贴板历史和持久化 Terminal 工作区。
  • 性能进程浏览、媒体来源应用图标。
  • Echo 桌宠导演层与 Codex 生命周期声音。

改进与修复

  • 统一工具箱的展开、收起和导航生命周期。
  • 减少 Hook 与转录双通道产生的重复声音。
  • 修复点击 Shelf 文件后 Island 可能卡死的问题。
