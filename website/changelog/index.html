CHANGELOG

每一次变化，
都应该值得被看见。

这里记录 WorkIsland 对真实工作流有意义的功能、修复和体验变化。提交历史属于工程，更新日志属于使用者。

LATEST STABLE 2026-09-05

v1.3.0

公测收口：Agent 自检自修、应用内反馈与新手引导就位，并修复更新提示与定位跳转两处关键体验问题。

新增

  • Agent Doctor 一键检测与一键修复：扫描全部 Agent 的 Hook 健康，自动备份修复并留痕，启动时自愈可修复状态。
  • 一键吐槽：设置内反馈入口，自动附带版本与 Agent 状态预填 GitHub issue。
  • 首启引导：尚未接入 Agent 时，灵动岛分步引导接入而非空白列表。
  • Bark 手机推送：审批、提问、完成、失败四类事件可推送到 iPhone，默认关闭、不含会话内容。
  • 会话回顾：岛收起期间的事件折叠为摘要，展开即可回顾。

改进与修复

  • 修复升级箭头重启后消失：24 小时内重启也会从缓存恢复升级提示。
  • 修复会话定位跳转：tmux 先选中对应 pane 再带回宿主窗口，VS Code 宿主不再被误判。
  • 修复工具箱图标点击不稳定：轻点不再被误判为拖拽。
  • Windows 版不再误报 macOS DMG 更新。

STABLE 2026-09-02

v1.2.0

应用内更新闭环与 MCP 产品助手落地；修复新版 ZCode 无法连接的问题。（原 v3.2.0 平移，同一构建）

新增

  • 应用内更新闭环：岛顶升级入口与「设置 → 关于 → 更新」同构，下载、SHA-256 校验、安装、自动重启一体完成。
  • MCP 产品助手：本地 MCP 服务可询问灵动岛功能、查询任务状态、诊断模块问题。
  • 外观模板系统与 workisland-cli template：模板可检查、预览、应用与恢复。

改进与修复

  • 修复 ZCode（≥3.10）始终无法连接：Hook 现在同步写入最近活跃项目的项目级配置。
