CLAUDE CODE · MACOS

Claude Code 完成提醒：在 Mac 上看见需要处理的任务

当 Claude Code 在后台运行时，真正打断工作流的通常不是任务本身，而是错过需要回答、审批或查看结果的时刻。WorkIsland 只把这些相关状态带到眼前，再让你回到对应会话继续处理。

适用：已在 Mac 上使用 Claude Code 的个人开发者更新：2026-09-05

你不需要一直盯着终端

并行跑几个任务时，反复切回每个终端去确认有没有完成，会打断正在进行的阅读、写作或会议。更有价值的是：任务状态变化后，能知道哪一个任务需要你，以及返回哪个上下文。

WorkIsland 是一个本地运行的 macOS 伴侣。它不替代 Claude Code、终端或编辑器；它读取已连接 Agent 的任务信号，在运行、等待处理、完成或失败时给出清晰状态。需要时，再从 Island 回到来源会话。

FIRST RUN

用一条真实任务完成验证

  1. 01

    安装并打开 WorkIsland

    下载 macOS 安装包后，将应用放入“应用程序”并打开。下载入口会优先使用已配置的镜像；镜像不可用时仍会回退到官方 GitHub Release。

  2. 02

    在 Agent 设置中连接 Claude Code

    选择你已经在使用的 Claude Code，并按应用内提示完成本地连接。连接未完成时，WorkIsland 不会显示伪造的“已完成”。

  3. 03

    运行一个真实任务并观察状态

    在原有终端中启动 Claude Code 任务。任务运行、等待你的操作或完成时，观察 Island；出现相关信号后，点击任务回到原来的终端或应用上下文。

适合什么场景？

你已经用 Claude Code 做长时间任务、会同时开多个会话，或不想通过轮询终端来确认每个任务的状态。它不会替你决定审批内容，也不会让 Agent 自动完成原本需要你处理的事项。

FAQ

常见问题

WorkIsland 会替代 Claude Code 或终端吗？

不会。你仍在原来的 Claude Code 与终端中工作；WorkIsland 只呈现本地任务状态，并在需要时帮助回到来源会话。

没有看到任务状态时该检查什么？

先在 WorkIsland 的 Agent 设置中确认 Claude Code 的本地连接已完成，再运行一条真实任务验证。连接没有完成时，应用不会伪造状态。

WorkIsland 会上传代码或会话内容吗？

不会。会话内容、代码、路径、项目名、主机名和用户名会留在你的 Mac 上。官网的访问与交互分析说明见产品手册的隐私章节。
