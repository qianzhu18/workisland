# WorkIsland

WorkIsland is a paid macOS productivity app for white-collar work. It brings
local Work Agent activity, approvals, questions, completions, reminders, and a
desktop pet into one low-distraction workspace.

This public repository is a binary release distribution point. Application
source code is not included here.

## Current release

- Version: `0.1.0 Internal`
- Target: macOS Apple Silicon (`arm64`)
- Download: [GitHub Releases](https://github.com/qianzhu18/workisland/releases)
- Package: `WorkIsland-0.1.0-arm64.dmg`
- SHA-256: `086e122502e9efab84ee91d6957c0c00291b8043513e083111324f554035edae`

This internal build is unsigned and is intended for testing. A signed,
notarized Mac App Store build will be published after the commercial release
checks are complete.
